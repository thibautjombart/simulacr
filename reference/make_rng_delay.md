# Turns a delay PMF into a random number generator

This function is used to create a random number generator from a
distcrete object, a function, or a set of numbers taken to be the PMF on
`0:(length(x) - 1)`. It internally uses `[make_pmf_delay()]` to turn its
input into a PMF, then samples delays from this PMF.

## Usage

``` r
make_rng_delay(x, max_delay = 1000)
```

## Arguments

- x:

  The sole input of the function, which can be any of 3 types: i) a
  `distcrete` object ii) a function returning a PMF (e.g. `dpois`),
  or iii) a vector of positive numbers taken as a probability mass
  function (pmf) on 0, 1, 2, ..., `(length(x) - 1)`, in which case it is
  standardised to sum to 1.

- max_delay:

  the maximum delay which can be generated by the random number
  generator

## Examples

``` r
# RNG from a poisson distribution
r_delay <- make_rng_delay(function(x) dpois(x, 2.5))
r_delay(10)
#>  [1] 4 5 2 2 4 1 1 1 2 4
summary(r_delay(1e4))
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
#>   0.000   1.000   2.000   2.497   3.000  10.000 

# RNG from an empirical weight distribution
r_delay <- make_rng_delay(c(0, 1, 1, 2, 4, 2, 1, 1, 0.5, 0.2))
r_delay(10)
#>  [1] 5 1 3 1 5 5 4 3 4 5
summary(r_delay(1e4))
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
#>   1.000   3.000   4.000   4.246   5.000   9.000 
barplot(table(r_delay(1000)))
```
