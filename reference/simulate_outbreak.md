# Simulate outbreaks with transmission trees

This function implements a contact-driven branching process outbreak
simulator. Outbreaks start with a single infection in an otherwise fully
susceptible population of size `n`on the first time step. New cases are
generated at each time step by infectious individuals, with forces of
infection depending on the generation time distribution, individual
transmission rates, and contacts between individuals. The function
returns a linelist including both non-cases and cases, as well as a
transmission tree listing all transmission events in the shape of a
`data.frame` with columns `from`, `to`, and `date`. This function is
user-facing; to use the `simulacr` engine in another package, you may
want to use the low-level function `[simulate_outbreak_step()]`.

## Usage

``` r
simulate_outbreak(
  n,
  duration = 1L,
  w = c(0, 1),
  tau = 0,
  contacts = NULL,
  label_size = 6
)
```

## Arguments

- n:

  An `integer` indicating the number of individuals in the population;
  no default.

- duration:

  An `integer` indicating the number of time steps to run the simulation
  for; defaults to 1L (i.e. only the initial infection is generated).

- w:

  The probability mass function of the generation time distribution, as
  produced by `[make_pmf_delay()]`, specified as a numeric vector, a
  function, or a `distcrete` object. Defaults to a point mass at 1 (i.e.
  all secondary infections take place exactly 1 time step after the
  primary infection).

- tau:

  A numeric vector of length `n` containing individual transmission
  rates; a single value will be recycled; defaults to 0 (no
  transmission).

- contacts:

  Contacts between all individuals in the population. It can be
  specified in two ways: i) an n x n matrix where entries correspond to
  contact presence or intensities, or ii) a function with a single
  argument `t` (time step) generating such matrix at each time step. If
  `NULL` (default), we assume random-mixing in the population, i.e. all
  individuals are in contact at every time step.

- label_size:

  An `integer` indicating the length of the labels generated by
  `[draw_labels()]`, used as unique individual identifiers. Defaults to
  6.

## Details

The force of infection (FOI) from individual \\i\\ to \\j\\ at time
\\t\\ is defined as:

\\\lambda\_{t, i \rightarrow j} = I\_{t,i} C\_{t, i \rightarrow j}
\tau\_{t,i} w(t - T_i)\\

The total FOI experienced by individual at time is summed over all
possible sources of infection: \\\lambda\_{t, \bullet \rightarrow j} =
S\_{t,j} \sum_i \lambda\_{t, i \rightarrow j} \\

It follows that individual \\j\\ becomes infected at time \\t+1\\
according to a Bernoulli distribution with probability: \\ 1 -
e^{-\lambda\_{t, \bullet \rightarrow j}} \\

To keep track of chains of transmission, the infector of \\j\\, denoted
\\alpha_j\\, is drawn from a Multinomial distribution weighted by the
respective FOIs directed towards \\j\\: \\ \alpha_j \sim \mathcal{M}(1,
\lambda\_{t, 1 \rightarrow j} / \lambda\_{t, \bullet \rightarrow j}
,\lambda\_{t, 2 \rightarrow j} / \lambda\_{t, \bullet \rightarrow j} ,
\ldots , \lambda\_{t, N \rightarrow j} / \lambda\_{t, \bullet
\rightarrow j} ) \\

  duration = 365, # simulate for a year

)
