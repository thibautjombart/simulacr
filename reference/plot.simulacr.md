# Plotting method for simulacr objects

The plot method for simulacr objects can be used to produce different
types of graphs, either interactive (by default) or static.

## Usage

``` r
# S3 method for class 'simulacr'
plot(x, method = c("visNetwork", "igraph", "tree"), cases_only = FALSE, ...)
```

## Arguments

- x:

  A `simulacr` object returned by
  [`simulate_outbreak()`](https://thibautjombart.github.io/simulacr/reference/simulate_outbreak.md).

- method:

  A character string indicating the plotting method: `"visNetwork"`
  (default) for an interactive plot, `"igraph"` for a static graph, or
  `"tree"` for a static tree with a time axis (also uses igraph).

- cases_only:

  A `logical` indicating if cases only should be included in the
  converted object; defaults to `FALSE`. Fixed to `TRUE` if `method` is
  "tree"

- ...:

  For `plot`, further arguments passed to
  [`epicontacts::plot.epicontacts()`](https://rdrr.io/pkg/epicontacts/man/plot.epicontacts.html)
  or
  [`igraph::plot.igraph()`](https://r.igraph.org/reference/plot.igraph.html).
  For "tree", `rescale = FALSE` and `asp = 0` are fixed.
