# Prune subtrees coming from specific cases

This function prunes a `simulacr` object by removing selected cases and
all their downstream infections.

## Usage

``` r
prune(x, ids = NULL, remove_stems = TRUE)
```

## Arguments

- x:

  A `simulacr` object as returned by
  [`simulate_outbreak()`](https://thibautjombart.github.io/simulacr/reference/simulate_outbreak.md).

- ids:

  A vector of `logical`, `integer`, or `character` indicating the subset
  of cases for which subtrees should be removed. Defaults to NULL, in
  which case no pruning takes place.

- remove_stems:

  A `logical` indicating if the cases from which subtrees are pruned
  should be removed as well. Defaults to `TRUE`.

## Value

A `simulacr` object.

## Author

Thibaut Jombart
